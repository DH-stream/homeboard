# RUNAI integration placeholder

RUNAI is expected to act as an API client rather than being hardcoded into core task logic.
The task API and `Task.source` field are prepared for future create/read/update/complete flows.

Future work:

- Token-scoped API authentication.
- OpenAPI schema for task endpoints.
- Audit trail for AI-created or AI-completed task instances.
- Household-level permissions and rate limiting.

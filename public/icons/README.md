# HomeBoard icon upload targets

Upload the generated PNG logo files into this folder using these exact filenames:

- `homeboard-icon-day-192.png`
- `homeboard-icon-day-512.png`
- `homeboard-icon-day-1024.png`
- `homeboard-icon-night-192.png`
- `homeboard-icon-night-512.png`
- `homeboard-icon-night-1024.png`

For iOS/Next App Router icons, upload the real PNG files here instead of this folder:

- `app/apple-icon.png` — 180×180 day icon for iOS Add to Home Screen
- `app/icon.png` — 512×512 day icon for Next/browser/app metadata

Notes:

- The installed PWA/iOS icon should use the day icon.
- Night icons are for future dynamic in-app branding only.
- Do not commit fake `.png` placeholder files. Replace with the real generated PNG assets.
